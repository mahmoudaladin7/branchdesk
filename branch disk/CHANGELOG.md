# Changelog

## 0.1.0 — 2026-10-06

First public beta.

- Added a local, read-only Git repository dashboard.
- Added project discovery, status and staging information, ahead/behind counts, commit history, local branches, and stash counts.
- Added search, filters, sorting, favorites, grid/list layouts, and quick search.
- Added dark/light themes, responsive layouts, keyboard support, and reduced-motion support.
- Added a fictional interactive demo and screenshots.
- Added integration tests for Git states, local API access checks, and filesystem boundaries.

See the README for known scope limits. No npm registry package is published with this release.
